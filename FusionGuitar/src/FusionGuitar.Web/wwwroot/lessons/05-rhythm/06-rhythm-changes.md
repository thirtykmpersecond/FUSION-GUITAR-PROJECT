# Rhythm Changes 结构与伴奏

## 1. 32 小节 AABA

Rhythm Changes 源自 Gershwin《I Got Rhythm》，32 小节 AABA，每个 A 段 8 小节。核心是和声套路 **I–VI–II–V**：

```
A:  Bb   G7   Cm7  F7 | Bb   G7   Cm7  F7   （I-VI-II-V）
A:  同上
B:  F7   F7   Bb   Bb | F7   F7   C7   C7    （Bridge，属循环）
A:  Bb   G7   Cm7  F7 | Bb   F7   Bb   ...
```

最著名的版本是 Charlie Parker 的《Anthropology》《Oleo》《Dexterity》——都是 Rhythm Changes 的即兴载体。

## 3. 伴奏要点

- **Freddie Green 式**：四拍扫一下，只弹 3-7 壳
- **Charleston 变体**：1、2& 或切分
- 关键：G7→Cm7→F7 的**声部连接**要顺（用 Drop2 就近指型）

:::progression chords="Bbmaj7,G7,Cm7,F7,Bbmaj7,G7,Cm7,F7" bpm="120" title="A 段两遍"

## 5. 练习

1. 用 120 BPM 弹 A 段 `Bbmaj7 G7 Cm7 F7` 的 3-7 壳，Freddie Green 四拍扫。
2. 换 Charleston 变体，右手切分扫，左手壳和弦不动。
3. 弹完整 AABA：A 两遍 → Bridge → A，全用壳 + Drop2 就近连接。
4. 用 /progressions 分别播放 A 段与 Bridge，跟着数小节、练声部连接。
