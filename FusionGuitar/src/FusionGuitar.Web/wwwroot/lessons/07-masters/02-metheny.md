# Pat Metheny：抒情长句与空间

## 1. 风格 DNA

Pat Metheny 的吉他风格辨识度极高：

- **乡村节奏底色**：受早期乡村/民谣影响，右手律动干净、有"拨弦感"
- **抒情长句**：大量级进（stepwise）和八度跳，旋律像"唱歌"
- **空间与留白**：句子之间大喘气，长音悬停
- **丰富的音色**：合唱/延时效果器营造开阔氛围

## 2. 抒情长句的结构

Metheny 的句子往往是"**级进爬升 + 八度跳 + 长音收尾**"：

```
起点 → 级进（2-3 个音）→ 八度跳 → 长音（悬停）→ 回落
```

他很少用琶音式跳来跳去，而是让旋律"走路"。

## 4. 分析

- 长音 E（和弦的 3）在句尾悬停，是"空间感"的关键
- 八度跳（B→C）打破级进的平淡，制造"惊喜"
- 句子长度适中（8 音），不啰嗦

## 5. 练习

1. 用 /licks 页的「Metheny 抒情长句」跟唱，注意长音的"悬停感"。
2. 把句子结构套到 G Dorian：级进 3 音 → 八度跳 → 长音（9）。
3. 在 Gmaj7 背景（/progressions）上即兴，强制每句都用长音收尾。
4. 挑战：把长音从 1 拍延长到 2 拍，体会留白如何让句子"呼吸"。
