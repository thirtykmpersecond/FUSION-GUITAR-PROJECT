# John McLaughlin：五声与印度色彩

## 1. 风格 DNA

John McLaughlin（Mahavishnu Orchestra 领袖）把**速度**和**精神性**带进了 Fusion：

- **五声堆叠**：大量用五声音阶/五声琶音，层层堆叠
- **印度色彩**：受印度古典音乐影响，使用装饰音、滑音（glissando）、非 12 平均律的微分音色彩
- **高速连奏**：16 分音符甚至更快，长时间保持
- **双音和声**：三度/六度双音旋律

## 2. 五声 + 连奏句子

McLaughlin 的句子常用**五声音阶的密集连奏**，配合印度式的滑音装饰。

## 4. 分析

- 五声音阶本身"安全"，但密集的 16 分连奏制造速度感
- 句子呈"波浪形"（上上下下），不是单向爬升
- 大量锤勾弦衔接

## 5. 练习

1. 用 /licks 页的「McLaughlin 五声堆叠」0.5x 连奏，全程锤勾弦。
2. 在 A 小调五声音阶（模块 1 学过）上，把句子整体平移，练连奏速度。
3. 加入滑音：每个句尾加一个无明确起点的滑音（glissando）。
4. 挑战：把句子从 0.5x 逐步加到 1.25x，保持每个音清晰（连奏不是糊）。
