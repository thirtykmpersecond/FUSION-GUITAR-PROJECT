# Drop3 与 Drop2+4 Drop-3 Voicings

## 1. 什么是 Drop3

Drop2 是把"从高往低数第 2 个音"降八度；**Drop3** 则是把"从高往低数第 3 个音"降八度。

以 Cmaj7（C E G B）为例，从高到低第 3 个是 E，降八度：

```
关闭位：C4 E4 G4 B4
Drop3 ：E3 C4 G4 B4
```

Drop3 的指型更宽、低音区更深，适合：低音双人组、独奏时的开放感、以及 **Drop2+4**（把第 2 和第 4 个音都降八度）——后者是四分音符织体中最"爵士"的声音之一。

:::voicing chord="Cmaj7" type="drop3" strings="1234"

## 2. Drop3 的指板特征

Drop3 通常跨越 4-5 品，手指要够得开。它比 Drop2 更"开"，低音在 ③ 或 ④ 弦上，上面三声部紧贴。

| 弦组 | 特征 |
|------|------|
| ①②③④ | 低音在第 ④ 弦，最常见的 Drop3 |
| ②③④⑤ | 更厚重，适合低音铺底 |
| ③④⑤⑥ | 低音极低，双人组独奏用 |

## 4. Drop2 vs Drop3 怎么选

- **要紧凑、伴奏时和旋律不打架** → Drop2
- **要开阔、低音区填充、独奏色彩** → Drop3
- 两种都要练，最终在指板上自由切换

## 5. 练习

1. 在 /voicings 里把 Cmaj7 切成 Drop3，弹 12 个指型（3 弦组 × 4 转位）。
2. Drop3 与 Drop2 交替：同一个 Cmaj7，先 Drop2 弹一遍再 Drop3 弹一遍，对比音色。
3. 用 Drop3 弹 C 大调 ii–V–I，注意手指跨度和低音的连接。
