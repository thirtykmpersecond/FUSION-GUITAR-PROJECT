# 上层三和弦与 So What 和弦 Upper Structures & the So What Chord

## 1. 上层结构 Upper Structure（US）

属和弦上叠一个**三和弦**（根音在属和弦上面），这个三和弦叫 Upper Structure。写法 `US-1`（大三在上）、`US-2`（小三在上）等。

| 记号 | 结构 | 实际和弦 |
|------|------|----------|
| C7 US-1 | D 大三 / C7 | C13#11 |
| C7 US-2 | Db 大三 / C7 | C7b9 |
| C7 US-3 | Eb 大三 / C7 | C7#9 |
| C7 US-4 | E 大三 / C7 | C7#9b13 |
| C7 US-5 | G 大三 / C7 | C7sus |

US 是高级 Fusion 的词汇：左手按属七根音 + 三全音，右手叠三和弦，张力极大。

## 2. So What 和弦

Miles Davis《So What》的和弦是两个音构成的叠置：**根音 + 四度 + 三度（P4 + M3）**，从 b3 开始弹，得到"闪亮的叠四"音色。

D Dorian 的 So What 和弦（两个把位）：

- 低把位：Dm7 框架 + 上方 G-C-F 叠置
- 高把位：叠置向上移到 12 品附近

## 4. 练习

1. 弹 C7 US-2（C7 + Db 大三）和 C7 US-3（C7 + Eb 大三），对比 b9 与 #9 的色彩。
2. 在 /voicings 里生成 Dm7 的 Drop2，叠一个 G 大三角在上方，试听"So What"质感。
3. 用 /progressions 播放 `Dm7,Dm7,Em7,Em7`（每和弦两小节），跟着弹 D-F-G-C 琶音。
4. 把 US 思路用到 V 级：G7 上叠 Ab 大三（= G7b9），听属张力。
