# 重配和声 Reharmonization

## 1. 三条思路

重配和声 = 保持旋律，换和弦。三条最常用的路：

1. **Diatonic Reharm（级数重配）**：把和弦换成同调内功能相同的另一个（如 IV 换成 ii，都指向 V）。
2. **Tritone Sub（三全音替代）**：把属和弦换成 bII7（第 5 课）。
3. **Modal Interchange（调式互换）**：借同主音小调的和弦，如 C 大调里用 bVII（Bb）、bVI（Ab）、bIII（Eb）。

## 2. 例子：C–Am–F–G 的重配

原始进行：`C  Am  F  G`（I–vi–IV–V，C 大调）。

一步步加料：

| 版本 | 进行 | 手法 |
|------|------|------|
| 原始 | C Am F G | — |
| +次属 | C **A7** F G | V7/vi |
| +替代 | C A7 F **Db7** | bII7 替代 G |
| +互换 | C A7 **Fm** Db7 | bVI（借小调） |
| 拉满 | **Em7 A7** Fm **G7 C** | 连锁 + 解决 |

:::progression chords="C,A7,F,Db7" bpm="72" title="重配进行：C A7 F Db7"

## 3. 保持旋律音

重配时最关键的是：**旋律音必须落在新和弦的和弦音里**。上面的 F 是固定旋律音：

- C（C-E-G）：F 不是和弦音 → 通常不放在强拍
- A7（A-C#-E-G）：F 是 b13（色彩）
- F（F-A-C）：F 是根音 ✓
- Db7（Db-F-Ab-Cb）：F 是 3 音 ✓

旋律音决定了哪些替代"合法"。

## 4. 练习

1. 拿 `C Am F G`，依次叠加 次属 → 替代 → 互换，每个版本都弹一遍并听变化。
2. 用 /progressions 播放 `C,Am,F,G` 和 `C,A7,F,Db7`，对比"朴素"与"色彩"两端。
3. 选一首你会的三和弦歌（如 I–IV–V），把其中 IV 或 V 换成三全音替代。
4. 记下旋律音是哪个，每次换和弦都确认它仍然在和弦内。
