# 三全音替代 Tritone Substitution

## 1. 原理：同一个三全音

属和弦的核心是 3 和 b7 之间的**三全音**（6 个半音）。有趣的是，两个相距三全音的属和弦**共享同一个三全音**：

| 和弦 | 3rd | b7 |
|------|-----|-----|
| G7 | B | F |
| Db7 | F | Cb（=B） |

G7 的 3（B）是 Db7 的 b7，G7 的 b7（F）是 Db7 的 3。所以 **Db7 可以替代 G7**，和声张力一样，但低音移动更有色彩（半音下行 b 到根音）。

## 2. 三全音替代 ii–V–I

C 大调里，把 V 级 G7 换成 bII7 = Db7：

```
Dm7 → G7 → Cmaj7
Dm7 → Db7 → Cmaj7
```

Db7 到 Cmaj7 的解决是**半音下行**，色彩更浓，是爵士标准曲的标配手法。

:::progression chords="Dm7,Db7,Cmaj7" bpm="70" title="ii–bII–I（三全音替代）"

## 3. 属和弦变形

三全音替代常与属和弦变形成对出现，给 V 级添加色彩音：

| 记号 | 含义 | 色彩 |
|------|------|------|
| G7b9 | 降九音 | 紧张、小调色彩 |
| G7#9 | 升九音 | "Hendrix"和弦、Funk |
| G7#11 | 升十一音 | Lydian 属、Fusion |
| G7b13 | 降十三音 | 更暗的属 |

:::staff clef="treble" key="C" time="4/4" notes="g/3+b/3+f/4+ab/4/w g/3+b/3+f/4+bb/4/w g/3+b/3+f/4+c#/5/w"

## 5. 练习

1. 在 C 大调 ii–V–I 里把 G7 换成 Db7，先只换 V 级。
2. 把练习 1 移到所有 12 个调（ii 用对应大调的 ii，V 用 bII7 替代）。
3. 在 /progressions 里播放 `Dm7,Db7,Cmaj7`，对比 `Dm7,G7,Cmaj7`，记住"半音解决"的音色。
4. 试弹 G7#9 的"Jimi 和弦"（Funk 中高频刷弦），感受属变形的听感。
