# 应用：ii–V–I

ii–V–I 是爵士与 Fusion 的"万能进行"。掌握它就掌握了标准曲的骨架。

## 大调 ii–V–I

以 C 大调为例：

```
Dm7  →  G7   →  Cmaj7
 ii      V       I
```

### 音阶选择

| 和弦 | 基础音阶 | 进阶选择 |
|------|----------|---------|
| Dm7 | D Dorian | D Aeolian, D Pentatonic Minor |
| G7 | G Mixolydian | G Altered, G Lydian Dominant, G Half-Whole Dim, G Bebop Dominant |
| Cmaj7 | C Ionian | C Lydian, C Bebop Major |

### V7 的音阶选择决定张力等级

- **Mixolydian**：温和，标准 Swing/Bebop
- **Lydian Dominant**：Fusion 味，#11 悬浮
- **Altered**：最紧张，所有变化音一起上
- **Bebop Dominant**：Mixolydian + 大七度经过音，Bebop 线条必备
- **Half-Whole Diminished**：半音包围，适合快速经过句

## 小调 ii–V–i

以 A 小调为例：

```
Bm7b5  →  E7b9  →  Am7 (或 AmMaj7)
  iiø       V7        i
```

### 音阶选择

| 和弦 | 音阶 |
|------|------|
| Bm7b5 | B Locrian 或 B Half-Diminished（旋律小调 6 级，更流畅） |
| E7b9 | E Phrygian Dominant（和声小调 5 级）或 E Altered |
| Am7 | A Dorian 或 A Aeolian |
| AmMaj7 | A Harmonic Minor 或 A Melodic Minor |

## 练习方法

1. **慢练和弦音**：在每个和弦上只弹 3-5-7（D-F-C, B-F-G, E-G-B），确保解决正确
2. **12 调循环**：按五度圈走，每天练一个调的 ii-V-I
3. **V7 变奏**：同一个 ii-I，V7 分别用 Mixolydian、Altered、Lydian Dominant，对比张力
4. **节奏**：先用全音符/二分音符，再到四分、八分、三连音、十六分
5. **背 Lick**：每个调背 2-3 条 ii-V-I 乐句，学到的语汇自然会出现在即兴中
