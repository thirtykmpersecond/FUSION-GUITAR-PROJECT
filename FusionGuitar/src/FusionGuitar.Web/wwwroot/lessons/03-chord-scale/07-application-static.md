# 应用：静态和弦 Static Chords

## 概念

ii-V-I 这类进行中，每个和弦只持续 1-2 小节，音阶选择相对"对号入座"。但在 Fusion/Funk 中，经常有一个和弦持续 4、8 甚至 16 小节（static chord / pedal point）。这时候如何保持音乐性？

答案：**在同一个和弦上切换不同音阶/调式，制造张力与释放。**

## 例子：在 Cmaj7 上

| 音阶 | 区别 | 色彩 |
|------|------|------|
| C Ionian | 自然 | 明亮、稳定 |
| C Lydian | #4 | 梦幻、飘浮 |
| C Lydian Augmented | #4 + #5 | 更紧张 |
| C Bebop Major | + #5 经过音 | 爵士线条 |
| C Major Pentatonic | 5 音 | 简单、旋律化 |

切换方法：在 C Ionian 弹 2 小节，C Lydian 弹 2 小节，回到 C Ionian。听感像"出去转了一圈又回来"。

## 例子：在 C7（属七）上

| 音阶 | 何时用 | 色彩 |
|------|--------|------|
| C Mixolydian | 默认 | Bluesy、Funk |
| C Mixolydian b13 | 小调色彩 | 暗、Fusion |
| C Lydian Dominant | #11 | 怪但酷 |
| C Altered | 最强张力 | Outside |
| C Half-Whole Dim | 半音经过 | Bebop |
| C Whole Tone | 飘浮 | 印象派 |
| C Blues | 蓝调 | 经典 |

## Side-slipping（侧滑）

高级技巧：在静态和弦上，短暂使用**根音上方/下方半音**的音阶。

例如在 Cmaj7 上弹 Db Lydian（侧滑到 Db），持续 1-2 拍后回到 C Ionian。这制造强烈的"outside"感，然后解决回来。

## 例子：在 Dm7 上

- D Dorian（默认）
- D Aeolian（换 b6，更暗）
- D Phrygian（加入 b2，异域）
- D Melodic Minor（大七度，Fusion）
- D Minor Pentatonic / Blues

## 练习

1. 选一个静态和弦（如 Cmaj7），循环伴奏 8 小节，每 2 小节换一个音阶
2. 录下自己的即兴，回听哪里有"张力-释放"感
3. 练习 side-slipping：在 Cmaj7 上滑入 Db Lydian 1 小节，再滑回
4. 用节拍器，每小节只弹一个目标音（音阶的 3 度或 7 度），其余用经过音填充
