# 调式互换 Modal Interchange

## 概念

**调式互换**：在大调（或小调）中，临时借用**同主音其他调式**的和弦。

以 C 大调为例，C Ionian 是"默认"。我们可以借：

- C Dorian 的 IV 级（bVII）= Bb
- C Phrygian 的 II 级（bII）= Db
- C Lydian 的 IV 级（#IV）= F#
- C Mixolydian 的 V 级（v）= Gm
- C Aeolian 的 III/VI/VII 级 = Eb / Ab / Bb
- C Locrian 的 vii° 等

## 常用借用和弦

| 借用和弦 | 来自 | 在 C 大调中 | 听感 |
|----------|------|-------------|------|
| bVII | Aeolian/Mixolydian | Bb | 摇滚/流行终止 |
| bVI | Aeolian | Ab | 戏剧、悲壮 |
| bIII | Aeolian | Eb | 民谣/英伦摇滚 |
| iv | Dorian/Aeolian | Fm | 暗化、浪漫 |
| bII | Phrygian | Db | 爵士、异域 |
| I#IVdim | Locrian | F#dim | 过渡 |

## 经典进行

### 1. bVII → I（摇滚终止）

```
C - Bb - C    （"Hey Jude" 结尾）
```

Bb 借自 C Aeolian，给大调注入一股"向下拉"的力量。

### 2. I - bVI - bVII - I（50 年代进行 / 悲情进行）

```
C - Ab - Bb - C
```

bVI (Ab) 和 bVII (Bb) 都来自 C Aeolian，比 vi-IV-V-I 更暗。

### 3. I - iv - V（小调 iv）

```
C - Fm - G
```

Fm 借自 C Dorian/Aeolian，让大调瞬间染上忧郁色彩。

## 指板上的思路

调式互换在吉他上的好处：**你可以在同一个根音位置上换音阶**。

例如 C 大调中出现 Bb 大七和弦（bVII）时，在 Bb 上弹 Bb Lydian（或 Bb Ionian），其他和弦保持 C 大调指型。不需要换把位，只需要"换头脑"。

## 练习

1. 分析 3 首你喜欢的歌，找出其中的借用和弦
2. 用 C - Am - F - G 与 C - Ab - Bb - C 对比弹，感受调式互换的色彩差
3. 在 12 小节布鲁斯中加入 bVII 和 bVI，听它们如何增加张力
