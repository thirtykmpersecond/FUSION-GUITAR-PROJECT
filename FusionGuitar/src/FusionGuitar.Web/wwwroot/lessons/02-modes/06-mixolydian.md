# Mixolydian 混合利底亚

## 公式

```
0  2  4  5  7  9  10
R  2  3  4  5  6  b7
```

**Mixolydian = 大调 + b7（小七度）**。

## 色彩

Blues、Rock、Funk、Fusion 中**最常用的属七和弦音阶**。b7 让它比大调"脏"一点，带蓝调味。

## 和弦

- G7 (G B D F) — Mixolydian 是 V7 和弦的默认音阶
- G9、G13
- 在 G7 上加 9 (A)、13 (E) 都是自然延伸音

## 与大调的区别

唯一不同：b7（F 而不是 F#）。这个 b7 强烈倾向解决到 3 度（B），所以在 G7 → Cmaj7 的进行中，F 自然落到 E。

## 蓝调叠加

在 G7 上用 G Mixolydian + 蓝调音（b3 = Bb、b5 = Db）就得到**属七蓝调音阶**：

```
0  3  5  6  7  10  + b3, b5 passing
```

## 练习

1. 在 G7 静态伴奏上弹 G Mixolydian，重点强调 3（B）和 b7（F）
2. 练习 F → E 的半音解决
3. 12 小节布鲁斯：每一级都用该调的 Mixolydian
