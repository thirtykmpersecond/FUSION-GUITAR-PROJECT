# 3-notes-per-string (3NPS) 指型

## 1. 为什么需要 3NPS

CAGED 指型每条弦上的音数不固定（2 或 3 个），换弦节奏不规则。
**3NPS** 让音阶在每条弦上恰好 3 个音，换弦对称、指法经济、速弹友好。

通常把大调音阶分成 7 个把位（position），每个把位都覆盖两个八度以上的音，根音出现在不同弦上。把这 7 个把位上下移动，就能覆盖整个指板。

## 2. 第一把位（6 弦根音 C，8 品起）

以 C 大调为例，最常用的 3NPS 第一式（每弦 3 音，共两个八度多）：

```
e |--8--10--12--    C  D  E
B |--8--10--12--    G  A  B
G |--7--9---10--    D  E  F
D |--7--9---10--    A  B  C
A |--7--8---10--    E  F  G
E |--8--10--12--    C  D  E
```

关键细节：

- 5 弦（A 弦）上的三个音是 **7-8-10**（E-F-G），指法 1-2-4，与其它弦的 1-3-4 不同 —— 这是因为 E-F 是半音
- 从 3 弦到 2 弦，整个手型会向后偏移 1 品（「B 弦偏移」），这是吉他调音造成的
- 根音 C 出现在：6 弦 8 品、4 弦 10 品、1 弦 8 品

## 4. 练习步骤

1. **节拍器慢练**：60 BPM，每拍 2 音，上下拨（alternate picking）。
2. **每弦 3 音，练到「闭眼也能换弦」**，再逐步加速。
3. **模进练习**：1-2-3-1、1-2-3-4、1-3-2-4 这类四音组上行/下行，是 Fusion / Shred 最基础的语汇。
4. **节奏变化**：前附点、三连音、六连音、五连音 —— 同样的音符配不同节奏，音乐性立刻不同。
5. **12 调循环**：按五度圈顺序（C–F–Bb–Eb–Ab–Db–B–E–A–D–G）每天练一个调，12 周后所有调都熟。

## 5. 3NPS vs CAGED

两者并不矛盾，专业吉他手通常两套都掌握：

- **CAGED**：和弦可视化好、与开放把位连接自然、适合伴奏与节奏
- **3NPS**：音阶线性演奏强、速弹与模进友好、适合即兴 Solo

学完后你会发现：**它们描述的是同一张指板**，只是切分方式不同。
