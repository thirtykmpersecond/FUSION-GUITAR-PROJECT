# 3-notes-per-string (3NPS) 指型

## 1. 为什么需要 3NPS

CAGED 指型每条弦上的音数不固定（2 或 3 个），换弦节奏不规则。
**3NPS** 让音阶在每条弦上恰好 3 个音，换弦对称、指法一致、拨弦节奏稳定，是速弹与线性演奏的基础。

大调音阶有 7 个音，对应 **7 个把位（position）**，每个把位根音落在不同的弦上。7 个把位连起来覆盖整个指板，上下平移即可在 12 个调之间切换。

## 2. Pattern 1：6 弦根音，C 大调 8 品起

最常用的第一式（每弦 3 音，覆盖两个八度 + 一个六度）。把位图如下（左侧弦序，数字为品数，括号内为手指编号）：

```
          1  3  4     (指法)
e |-----8--10-12--    C  D  E
B |-----8--10-12--    G  A  B
G |-----7--9--10--    D  E  F
D |-----7--9--10--    A  B  C
A |-----7--8--10--    E  F  G
E |-----8--10-12--    C  D  E
          1  2  4
```

下面是该 Pattern 从 C4 到 C5 的单音上行（五线谱 + TAB，使用 Pattern 1 的把位）：

逐弦验证（以 MIDI/音名为准）：

逐弦验证（以 MIDI/音名为准）：

| 弦 | 空弦音 | 品 → 音 |
|----|--------|---------|
| ⑥ E | E2 | 8=C, 10=D, 12=E |
| ⑤ A | A2 | 7=E, 8=F, 10=G |
| ④ D | D3 | 7=A, 9=B, 10=C |
| ③ G | G3 | 7=D, 9=E, 10=F |
| ② B | B3 | 8=G, 10=A, 12=B |
| ① e | E4 | 8=C, 10=D, 12=E |

指法要点：

- ⑥④③②①弦上是 **1-3-4**（食指 + 小指 + 无名指/小指）或 **1-2-4**
- ⑤弦上是 **1-2-4** —— 7-8 之间只有半音，食指到中指就够，不需要伸展
- 根音 C 的三个位置：**⑥弦 8 品、④弦 10 品、①弦 8 品**，练习时眼睛盯着这三个 C

## 3. B 弦偏移（B-string offset）

吉他 ③ 弦（G）到 ② 弦（B）之间是大三度，其他相邻弦都是纯四度。这造成：

- ⑥⑤④③弦上的 3NPS 手型可以原样平移
- 到了 ②①弦，整个手型必须**向高把位方向挪 1 品**

在 Pattern 1 里你能直接看到：③弦是 `7-9-10`，②弦变成 `8-10-12`，整体后移 1 品。这是物理事实，不是例外，所有 3NPS / CAGED 指型都会遇到。

## 4. 七个把位

大调音阶 7 个音，每个音都能作为一个 3NPS 把位的「入口」，于是有 7 个相邻的把位覆盖整个指板。不同教材对 7 个把位的编号顺序略有差异（有的按 ⑥弦起始音编号，有的按 CAGED 形状对应编号），但**物理上的指板是同一张**。

在 C 大调里，以 Pattern 1（⑥弦根音 C 在 8 品）为锚点：

- 向上（高把位方向）依次是以 D、E、F、G、A、B 为入口的把位，最后回到高八度的 Pattern 1
- 向下（低把位方向）依次是以 B、A、G、F、E、D 为入口的把位
- 相邻把位在指板上**首尾重叠 2–3 个音**，换把时用滑音 / 击勾弦即可无缝连接

建议学习路径：

1. 先把 **Pattern 1** 在 12 个调里练到能脱稿
2. 再学与它相邻的「高一个位置」和「低一个位置」两个把位
3. 最后补全中间的把位，目标是**任何音都能从多个方向到达**

具体 2–7 号把位的指法会在模块 2（调式理论）中随调式一起展开 —— 那时你会理解为什么这些把位同时也是 Dorian / Mixolydian 等调式的指型。

## 6. 练习步骤

1. **节拍器慢练**：60 BPM，每拍 2 音，上下拨（alternate picking），先练上行再下行。
2. **每弦 3 音，练到闭眼也能换弦**，再以每周 5–10 BPM 的速度提升。
3. **模进练习**：
   - 三音组：1-2-3、2-3-4、3-4-5 …
   - 四音组：1-2-3-4、1-3-2-4
   - 反向、跳进、节奏移位 —— 同样的指板，无限的语汇
4. **节奏变化**：八分、三连音、十六分、前附点、六连音、五连音。音符不变，音乐性立刻不同。
5. **12 调循环**：按五度圈移动 Pattern 1 —— C → F → B♭ → E♭ → A♭ → D♭ → G♭(=F♯) → B → E → A → D → G，每天一个调，12 周贯通。

## 7. 3NPS vs CAGED

两者不矛盾，专业吉他手通常两套都掌握：

- **CAGED**：和弦可视化好、与开放把位连接自然、适合伴奏与节奏
- **3NPS**：线性演奏强、换弦规则、速弹与模进友好、适合即兴 Solo

它们描述的是**同一张指板**，只是切分方式不同。CAGED 帮你看到和弦形状，3NPS 帮你跑句子，最终目标是在两种视图之间自由切换。
