# CAGED 系统

## 1. 核心思想

CAGED 用 **5 个开放和弦形状**（C、A、G、E、D）作为「模具」，把它们平移到指板任何位置，就能在所有 12 个调里构造同一个和弦。

以 C 大调为例，五个形状在指板上从低到高依次出现：

```
| C 形 | A 形 | G 形 | E 形 | D 形 |
  3fr   5fr   7fr   8fr   12fr ...
```

每个形状都包含完整的和弦音，并且彼此**在指板上重叠连接**，形成覆盖全把位的网。

## 2. 五个形状与根音位置

| 形状 | 根音所在弦 | 横按品位（C 大调） |
|------|-----------|------------------|
| C | 5 弦 / 2 弦 | 0 |
| A | 5 弦 | 3 |
| G | 6 弦 / 3 弦 | 5 |
| E | 6 弦 | 8 |
| D | 4 弦 | 10 |

记住**根音位置**比记住形状本身更重要 —— 任何和弦、任何音阶都能挂在这 5 个根音位置上。

## 3. 从和弦到音阶

CAGED 不仅是和弦系统。每个和弦形状对应一个大调指型（也叫 **pattern / position**）：

- C 形 → C 大调音阶 Pattern 1
- A 形 → Pattern 2
- G 形 → Pattern 3
- E 形 → Pattern 4
- D 形 → Pattern 5

练习方法：先按好和弦，再把该形状里的**经过音**（和弦之间的音阶音）补出来，就得到整个把位的大调音阶。

## 5. 练习

1. 每天只练一个形状：在 12 个调中移动该形状弹奏和弦 → 琶音 → 音阶。
2. 周一 C 形、周二 A 形、周三 G 形、周四 E 形、周五 D 形，周末串起来。
3. 用伴奏带在 C 大调下，从 C 形开始依次即兴，每个形状弹 8 小节后换把位，听根音连接是否顺畅。

## 6. 常见坑

- 只在「把位方块」里弹，不关心根音位置 → 移调时混乱。**永远先找根音。**
- 把五个形状当孤立图形背。应当把它们看作**同一张指板地图上相邻的 5 个窗口**。
- 忽略 B 弦调音差。CAGED 在 B 弦上所有形状都要整体偏 1 品，这是物理事实，不是例外。
