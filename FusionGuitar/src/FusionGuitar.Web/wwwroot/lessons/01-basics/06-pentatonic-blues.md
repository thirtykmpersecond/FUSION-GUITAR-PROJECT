# 五声音阶与蓝调音阶

Pentatonic & Blues Scales

## 1. 五声音阶：去掉「危险音」

**大调五声音阶（Major Pentatonic）**：从大调音阶中去掉 IV 级和 VII 级：

```
Major:        0  2  4  5  7  9  11
Major Penta:  0  2  4  7  9              （去掉 5、11）
```

**小调五声音阶（Minor Pentatonic）**：从自然小调中去掉 II 级和 bVI 级：

```
Natural Minor: 0  2  3  5  7  8  10
Minor Penta:   0  3  5  7  10            （去掉 2、8）
```

**关键事实**：A 小调五声音阶与 C 大调五声音阶是**同一组音**（关系大小调），只是主音不同。这是为什么吉他手一个指型能在大、小调和弦上都即兴的根本原因。

下面是 A 小调五声音阶在五线谱上的写法：

:::staff clef="treble" key="Am" notes="a/4/8 c/5/8 d/5/8 e/5/8 g/5/8 a/5/8 c/6/8 a/5/8"

## 2. 蓝调音阶：加入蓝色的音

在小调五声音阶基础上加入 **b5（三全音）**：

```
Blues: 0  3  5  6  7  10
       R  b3 P4  b5 P5 b7
```

b5 这个音就是"blue note"，带有嘶吼、下滑、哭泣的色彩。Solo 时通常**经过**它（chromatic passing），而不是长时间停留。

## 3. 指板上的五声指型

最经典的小调五声音阶第一式（6 弦根音，A 小调，5 品起）：

```
e |--5--8--
B |--5--8--
G |--5--7--
D |--5--7--
A |--5--7--
E |--5--8--
```

## 4. 大调五声 vs 小调五声

同一组音（A 小调五声 = C 大调五声），落点不同，听感完全不同：

- 强调 **A** 作为目标音 → A 小调五声，适合在 Am7 上即兴
- 强调 **C** 作为目标音 → C 大调五声，适合在 Cmaj7 上即兴
- 强调 **D** 作为目标音 → D Dorian 色彩
- 强调 **G** 作为目标音 → G Mixolydian 色彩

这是 Fusion 即兴的核心心法之一：**同一组音，强调不同的音，就是不同的调式色彩。**

## 5. 五种五声把位

和 CAGED 类似，小调五声音阶有 5 个标准把位，根音分别落在 6 弦、6 弦（偏移）、5 弦、4 弦、3 弦。5 个把位连起来覆盖整个指板，每个把位练熟之后，Solo 时不再被困在一个把位里。

## 6. 练习

1. **背指型**：一周只练一个把位，节拍器 60 BPM 上下行。
2. **连把位**：用滑音/击勾弦把相邻把位横向连起来。
3. **蓝调音加花**：在五声句子中加入 b5 经过音，听蓝调色彩。
4. **跟伴奏**：用 A 小调五声分别在 Am、Dm、Em（i–iv–v）上即兴，注意目标音的选择。
5. **大调五声练习**：同样指型，在 C、F、G（I–IV–V）上即兴，强调 C/F/G 为落点，听大调色彩。
