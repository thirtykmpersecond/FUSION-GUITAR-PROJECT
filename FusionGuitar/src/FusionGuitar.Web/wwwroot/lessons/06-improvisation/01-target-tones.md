# 目标音导向 Target Tones

## 1. 即兴不是"跑音阶"

很多人即兴只会在音阶里上下跑，听起来像"练习曲"。真正的即兴是**一句一句地说**，而每一句都要落在**目标音**上。

目标音 = 当前和弦里最有"落点感"的音：

- 和弦的 **3**（决定大小色彩）和 **7**（决定七和弦类型）——最稳的落点
- 和弦的 **9、11、13**（色彩音）——更有爵士味的落点
- 调式里要强调的**特征音**（如 Dorian 的大 6、Lydian 的 #4）

## 2. 一句即兴的骨架

任何一句都可以拆成：**出发 → 经过 → 落点**。用 D Dorian 练：

- 出发：D（根音）或 F（b3）
- 经过：任意音阶音，快
- 落点：C（7）或 B（大 6，Dorian 特征音）

## 3. 先唱再说

在弹之前，先**用嘴唱**这句的轮廓（上行、下行、跳进、级进）。唱得出来，手指才跟得上。这是所有大师即兴的共同习惯。

## 4. 练习

1. 在 Dm7 上，只弹 F（b3）和 C（7）两个落点音，中间用 D Dorian 的经过音连起来。
2. 把上面的 Lick 速度从 0.5x 慢慢加到 1x，注意**每个落点都要"立得住"**。
3. 换目标音：落点在 E（9）、G（4/11）、B（大6）上各造一句。
4. 用 /licks 页的 Dorian 两个 Lick，先听、再跟、最后不看谱复述。
