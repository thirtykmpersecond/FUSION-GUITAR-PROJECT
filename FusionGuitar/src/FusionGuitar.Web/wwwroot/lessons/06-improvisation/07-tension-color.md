# 色彩音与张力 Tension & Color Tones

## 1. 在落点前"绕一下"

专业即兴和普通音阶跑动的最大区别：**色彩音 + 半音包围**。

色彩音就是和弦的 9、11、13 以及调式的特征音。把它们放在落点音**之前**，形成"绕进去"的效果：

```
目标音：C（Cmaj7 的 7）
先绕：B  C#  C     （半音上行包围）
先绕：B  Bb  C     （半音下行包围）
先绕：A  B  C      （级进）
```

## 4. 练习

1. 在 Dm7 上，目标音 C，练三种"绕进去"（半音上/半音下/级进）。
2. 用 /licks 页的「半音经过句」和「Altered 属琶音」对照听：一个温和、一个紧张。
3. 给 ii–V–I 加色彩：Dm7 用 9（E）落点、G7 用 #11（C#）落点、Cmaj7 用 9（D）落点。
4. 记住原则：**色彩音当经过、和弦音当落点**。
