# Pat Martino：减和弦系统

## 1. 风格 DNA

Pat Martino 的思维建立在**减和弦（diminished）系统**上：

- **减和弦包含所有变化音**：减七和弦（0-3-6-9）是对称的，任意移三个半音都是同一个和弦
- **线性和声**：他用减和弦把复杂的 ii–V–I 简化成"上下移动的线"
- **高音区琶音**：快速、密集、在指板上横扫

## 2. 减和弦的对称魔力

减七和弦（dim7）四个音两两相距小三度，完全对称：

```
Cdim7: C  Eb  Gb  A
Ebdim7: Eb  Gb  A  C    （整体 +3 半音 = 同一个和弦）
```

这意味着：**一个减七指型，移三品就是另一个转位**。Martino 大量利用这点做模进。

## 4. 练习

1. 找出 Cdim7 指型，整体 +3、+6、+9 品，确认音还是同一组。
2. 在 G7 上用 G#dim7 琶音弹一句，解决到 Cmaj7。
3. 把 ii–V–I（Dm7–G7–Cmaj7）替换成：Dm7 → G#dim7 → Cmaj7，听紧张感。
4. 用 /licks 页的「Altered 属琶音」体会减结构的张力。
