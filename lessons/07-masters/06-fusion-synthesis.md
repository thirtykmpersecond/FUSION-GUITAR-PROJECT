# Fusion 风格综合：拼出自己的语汇

## 1. 大师即模块

把前面学的大师 DNA 当成"可组合的模块"：

| 大师 | 拿什么 | 用到哪 |
|------|--------|--------|
| Holdsworth | 四度叠置 + 连奏流动 | 长句、和声色彩 |
| Metheny | 抒情长句 + 空间 | 主旋律、安静段落 |
| Martino | 减和弦 + 对称模进 | 属和弦变化 |
| Scofield | 蓝调音 + 歪斜节奏 | 律动、funky 段落 |
| McLaughlin | 五声堆叠 + 高速连奏 | 高潮、速度段落 |

## 2. 一首即兴的"剧情"

好的 Fusion 即兴像一篇文章，有起承转合：

```
开头：Metheny 式长句 + 空间（先说话，不炫技）
发展：Holdsworth 式四度流动
转折：Scofield 式蓝调歪句（换律动）
高潮：McLaughlin 式五声连奏（速度）
收尾：回落 + 长音悬停（回到空间）
```

## 3. 组合练习

在 Dm7–G7–Cmaj7 上，4 小节一个"模块"地拼：

:::progression chords="Dm7,G7,Cmaj7" bpm="90" title="组合练习背景"

第 1-4 小节：Metheny 抒情（级进 + 长音）
第 5-8 小节：Holdsworth 流动（连奏 + 四度）
第 9-12 小节：Scofield 歪句（切分 + 蓝调音）
第 13-16 小节：McLaughlin 连奏（五声 + 速度）

## 4. 练习

1. 先分别练熟每个"模块句子"（用 /licks 页挑 4 个对应风格的 Lick）。
2. 按上面的"剧情"顺序，4 小节一个模块地接起来。
3. 录音回放，检查：是否有剧情起伏？还是所有段落听起来一样？
4. 挑战：给每个模块写自己的"变体"，逐步脱离原 Lick。
