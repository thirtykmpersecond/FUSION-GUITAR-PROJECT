# 次属和弦与连锁 ii–V Secondary Dominants

## 1. 给任意和弦配属和弦

"次属和弦（Secondary Dominant）"指：**把某个调内和弦当作临时的 I，给它配一个 V7**。

例如 C 大调里：

- Dm7（ii）→ 临时 I 是 D，V7/D = **A7**（不是调内，但指向 D）
- G7 本身是 V（V7 of I）
- Am7（vi）→ V7/vi = **E7**

写法是 `V7/x`，读作"x 的属"。次属和弦能制造暂时的张力，让和声前进感更强。

## 2. 常用次属进行

| 进行 | 临时目标 | 效果 |
|------|----------|------|
| **A7 → Dm7** | ii | 最常见，Dorian 色彩 |
| **E7 → Am7** | vi | 小调色彩 |
| **D7 → Gm7** | iii | 更罕见 |
| **B7 → Em7** | iii/vi | 也常见 |

:::progression chords="Dm7,A7,Dm7,G7,Cmaj7" bpm="75" title="次属 A7 → Dm7"

## 3. 连锁 ii–V（ii-V of ii-V）

在次属和弦前面再加一个它的 ii，就变成**连锁 ii–V**：

```
简单：A7 → Dm7 → G7 → Cmaj7
连锁：Em7 A7 Dm7 G7 Cmaj7   （Em7 是 A7 的 ii）
```

这像俄罗斯套娃：每个目标都被"ii–V 再包一层"。Backcycling（反向循环）是爵士编曲的核心工具之一。

:::progression chords="Em7,A7,Dm7,G7,Cmaj7" bpm="75" title="连锁 ii–V：Em7 A7 Dm7 G7"

## 5. 练习

1. 弹熟 `Dm7 A7 Dm7 G7 Cmaj7`，注意 A7 如何"拽"向 Dm7。
2. 给 C 大调的每一级都配一个次属：A7(→ii)、E7(→vi)、D7(→iii)、B7(→vi?)、C7(→IV F)。
3. 把连锁 ii–V 拉长：`Am7 D7 Gm7 C7 Fmaj7`，体会"每次解决都被再延长一步"。
4. 在 /progressions 里比较 `Dm7,G7,Cmaj7` 与 `Em7,A7,Dm7,G7,Cmaj7` 的紧张感差异。
