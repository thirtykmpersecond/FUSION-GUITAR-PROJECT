# 节奏感觉 Straight / Swing / 16th-note Feel

## 1. 三种基本感觉

同样的八分音符，演奏时间点不同，感觉完全不同：

| 感觉 | 八分音符位置 | 听感 | 常见音乐 |
|------|--------------|------|----------|
| **Straight 直拍** | 均分 | 均匀、机械、推进 | Rock、Funk、Fusion 的基础 |
| **Swing 摇摆** | 三分律动（摇摆三连音） | 松散、律动感强 | Jazz、Blues |
| **16th 十六分** | 每个八分拆成两半 | 密集、忙碌 | Funk、Fusion 主音 |

Swing 不是"把音符拖长一点点"，而是**三连音感觉**：每个四分音符被均分成三个八分，演奏第 1 和第 3 个（长-短-长-短）。

## 2. 节拍器练习

用「和弦进行」页面的播放器配合节拍器练节奏：

- 开节拍器 60 BPM，先弹 straight 八分，再切到 swing 感觉（想象"长-短-长-短"）
- 感受：**时值不变，律动点变了**

## 3. Fusion 里怎么用

Fusion（融合爵士）通常**不是**纯 Swing，而是 straight 16th 为主，偶尔混入 swing 八分：

- 伴奏：straight 16th Funk 切分
- 主音：16th 密集句子 + 偶尔 swing 的"呼吸"
- 这是 Fusion 区别于传统 Jazz 的关键——**律动底子是 Funky，色彩是爵士的**

## 4. 练习

1. 节拍器 60，弹 Dm7 的 3-7 壳，先 straight 八分，再 swing 八分，耳朵盯紧差别。
2. 把同一段壳和弦的 comping 从 straight 切到 swing，感受伴奏"活"起来。
3. 用 16th 感觉弹 C 大调音阶上下行，保持均匀——这是 Funk 的呼吸。
4. 记住：Fusion 的默认律动是 straight 16th，先打稳，再加切分。
