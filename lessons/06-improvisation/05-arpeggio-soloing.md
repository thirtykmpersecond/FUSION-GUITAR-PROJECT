# 和弦音即兴：把和弦弹成句子 Arpeggio Soloing

## 1. 和弦音是第一落点

即兴时，**和弦音（arpeggio tones）永远优先**。跑音阶是"经过"，落和弦音是"说重点"。

每个和弦先抓它的琶音：

| 和弦 | 琶音 |
|------|------|
| Cmaj7 | C E G B |
| Dm7 | D F A C |
| G7 | G B D F |
| Am7b5 | A C Eb G |

## 2. 琶音 + 经过音的句子

一个最实用的句型：**琶音上行 + 音阶经过音下行**。

G7 上弹琶音（G-B-D-F）然后经过 A（9）回落：

## 3. 属七琶音的紧张感

属七和弦（V7）的琶音里有 3-b7 的三全音（G7：B-F），张力最强。把它弹成句子，再解决到 I 级和弦音。

:::lick name="Bebop 属七包围" bpm="80"

## 4. 练习

1. 把 C 大调 ii–V–I 的三个琶音（Dm7、G7、Cmaj7）在指板上找全，各 2 个把位。
2. 琶音上行 + 经过下行，在 Dm7 上造一句，落点在 C（7）。
3. 属七琶音句子（G7）后接 Cmaj7 琶音句子，体会"紧张→解决"。
4. 用 /licks 页的 Mixolydian 和 Bebop 两个 Lick 对照练习。
