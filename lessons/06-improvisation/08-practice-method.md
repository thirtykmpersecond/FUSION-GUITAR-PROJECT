# 即兴练习方法论 Improvisation Practice Method

## 1. 四个练习支柱

把即兴练习拆成四块，每天各占一点时间：

| 支柱 | 内容 | 工具 |
|------|------|------|
| 音阶/琶音 | 调式音阶、和弦琶音、把位 | /fretboard、/voicings |
| 句子积累 | 学 Lick、拆动机 | /licks、本模块课程 |
| 节奏 | 切分、空间、变速 | 节拍器、模块 5 |
| 实战 | 跟背景即兴 | /progressions |

## 2. 一个"30 分钟即兴日常"模板

```
0:00-5:00   热身：D Dorian 音阶 + 琶音，两个把位，0.75x
5:00-10:00  句子：学一个新 Lick（/licks），0.5x 弹准
10:00-15:00 拆解：找出 Lick 的动机核，做移位 + 变尾
15:00-25:00 实战：ii–V–I 背景（/progressions），只用一个动机发展
25:00-30:00 录音回放：数留白比例、落点是否都在和弦音上
```

## 3. 每周一个"主题"

本周只练一个东西，练透它：

- 本周：Dorian 句子 + 6 度跳进
- 下周：属七琶音句子 + Altered
- 再下周：半音包围 + 目标音 C

:::lick name="Dorian 六度跳进" bpm="85"

## 4. 检查清单（每次练习后过一遍）

- [ ] 落点音是不是和弦音？
- [ ] 有没有留白（空拍比例 > 30%）？
- [ ] 句子有没有重复/动机感？
- [ ] 能不能 0.75x 弹准、再 1x 不慌？
- [ ] 能不能立刻平移一个调？

## 5. 练习

1. 按上面的 30 分钟模板跑一遍。
2. 用 /licks 页挑 1 个新 Lick，完成"拆动机 → 移位 → 变尾"三步。
3. 打开 /progressions 的 ii–V–I（90 BPM），用**单一动机**即兴 4 分钟。
4. 录音，回放时对照检查清单打勾。
