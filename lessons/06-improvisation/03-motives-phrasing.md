# 动机与句法 Motives & Phrasing

## 1. 一句话，反复说

即兴最强大的工具是**动机（motive）**：一个短小的音型，通过重复和变化，让整段即兴有"主题感"，而不是零散的音。

常见的动机发展手法：

| 手法 | 说明 | 例子 |
|------|------|------|
| 重复 | 原样再来 | X X X |
| 移位 | 整体升高/降低 | X → 升高 2 品 |
| 倒影 | 上下反过来 | 上行 → 下行 |
| 增值/减值 | 拉长/缩短时值 | 每音 2 拍 → 每音 1 拍 |
| 变尾 | 开头不变改结尾 | 落在不同目标音 |

## 3. 练习：一个动机发展成 8 小节

1. 用 3 个音造一个动机（如 D-E-F）。
2. 第 1-2 小节原样重复。
3. 第 3-4 小节整体升高 2 品（移位）。
4. 第 5-6 小节倒影（反着弹）。
5. 第 7-8 小节变尾，落在 G（和弦音）上。

## 4. 练习

1. 用 /licks 页的任意 Lick，找出它的"动机核"（最短可重复片段）。
2. 把动机核做移位：整体 +2、+4 品各弹一遍。
3. 把动机核倒影：上行改下行。
4. 在 ii–V–I 背景上，把一个 3 音动机"说 8 遍"，每遍只改落点音。
