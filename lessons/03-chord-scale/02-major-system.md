# 大调体系

在大调顺阶和弦上，每个和弦都有一个"默认"音阶：

| 和弦 | 默认音阶 | 特征 |
|------|----------|------|
| Imaj7 | Ionian (或 Lydian) | 稳定，可选 #4 |
| ii7 | Dorian | 自然 6、13 |
| iii7 | Phrygian | 慎用 b2 |
| IVmaj7 | Lydian (或 Ionian) | #4 让它飞起来 |
| V7 | Mixolydian | b7 必须 |
| vi7 | Aeolian (或 Dorian) | b6 或 6 |
| viiø7 | Locrian | b5 是核心 |

## 最常用：ii - V - I

C 大调的 ii-V-I：

```
Dm7  →  G7   →  Cmaj7
Dorian   Mixo    Ionian/Lydian
```

在 Dm7 上弹 D Dorian（= C 大调音阶，主音 D）。
在 G7 上弹 G Mixolydian（= C 大调音阶，主音 G）。
在 Cmaj7 上弹 C Ionian 或 C Lydian。

**关键洞察**：这三个音阶使用的音完全相同（C 大调音阶），只是主音和强调点不同。在指板上你甚至不需要换把位，只需要换"落点"。

## 四级为什么用 Lydian

IVmaj7 在大调中是下属功能，它的 4 度（b7 of IV）实际上是调式的 7 度（leading tone）。用 Lydian 的 #4 可以避免 4 度与 3 度的小二度摩擦，让 IV 和弦更飘浮。

例如 C 大调中 Fmaj7：
- F Ionian：F G A Bb C D E (Bb = 调式 b7)
- F Lydian：F G A B C D E (B = 调式 natural 7)

F Lydian 的 B 是调式音，比 F Ionian 的 Bb 更"对"。
