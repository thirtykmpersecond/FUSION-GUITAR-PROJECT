# 和弦-音阶理论入门

## 核心问题

**给一个和弦，应该弹什么音阶？**

这就是 Chord-Scale Theory 要回答的问题。一个和弦由若干音构成，而一个音阶包含 7 个音。音阶中必须包含和弦的所有"和弦音（chord tones）"，其余的音作为"张力（tensions）"或"经过音（passing tones）"。

## 匹配原则

1. 音阶的根音 = 和弦的根音
2. 音阶必须包含和弦的 3 度、5 度、7 度
3. 音阶中额外的音（9、11、13）要么是"可用张力"，要么作为经过音处理

## 一个和弦，多个音阶

以 Cmaj7 为例，它可以匹配：

| 音阶 | 区别 | 听感 |
|------|------|------|
| C Ionian | 自然 4 度（F） | 明亮、教科书 |
| C Lydian | #4（F#） | 梦幻、飘浮 |
| C Bebop Major | Ionian + #5 | 爵士线条 |

同一个和弦，选不同音阶就有不同色彩。这就是 Fusion 即兴的核心。

## 本模块路线

1. 大调体系：每个顺阶和弦对应什么音阶
2. 旋律小调体系：Lydian Dominant、Altered 等 Fusion 武器
3. 和声小调体系：Phrygian Dominant 等
4. 对称音阶：全音音阶、减音阶
5. 应用：ii-V-I 和静态和弦
