# Lydian 利底亚

## 公式

```
0  2  4  6  7  9  11
R  2  3  #4  5  6  7
```

**Lydian = 大调 + #4（增四度，三全音）**。

## 色彩

梦幻、飘浮、电影配乐感。#4（F# in C Lydian）是唯一的特征音，它解决到 5 度（G）的倾向比 Ionian 的自然 4（F）弱得多，所以听感"悬而未决"。

经典用法：

- **Fusion / Jazz**：maj7#11 和弦（Cmaj7#11 = C E G B F#）
- **电影配乐、Joe Satriani**（"Flying in a Blue Dream"）
- **Allan Holdsworth**：几乎所有 Maj7 句子都用 Lydian

## 和弦

- Cmaj7#11 (C E G B F#)
- Cmaj9#11
- Cmaj13#11

在普通 Cmaj7 上也可以用 C Lydian，F# 作为 Upper Structure 音。

## Lydian vs Ionian

唯一的差别是 F vs F#。在 Cmaj7 伴奏上：

- C Ionian：稳定，但 F 与 E（三音）小二度摩擦
- C Lydian：F# 没有摩擦，更"飘浮"

## 练习

1. 在 Cmaj7 持续音上，先弹 C Ionian，再把所有 F 换成 F#，听色彩转变
2. 练习 #4 → 5 的解决：F# → G
3. 用 C Lydian 在 Cmaj7#11 上即兴，目标音落在 E、G、B、F#
